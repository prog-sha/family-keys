How it works

  1. Register

    Save a credential with an ENV name and a purpose. Add two-factor setup to the same item if needed.

  2. Find

    Connect your agent through MCP. It searches names and purposes and receives metadata.

  3. Deliver

    Fetch the values in an authenticated, encrypted payload. Append them to a local .env or pass them to a local command.

Run it on a trusted LAN

Start on localhost and allow only the devices you need. Two-factor setup details are write-only and can be replaced from the vault.
